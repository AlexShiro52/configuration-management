# Краткое объяснение для защиты

## Что делает программа

Это визуализатор зависимостей Python-пакета. Вход - имя пакета и адрес
репозитория либо тестовый JSON. Выход - граф D2 и PNG. Для демонстрации
промежуточных результатов предусмотрены режимы --stage 1, 2, 3, 4.

Получение зависимостей написано самостоятельно: urllib запрашивает JSON,
json разбирает ответ, поле info.requires_dist содержит требования.
Сторонние библиотеки и менеджеры пакетов для этого не используются.
D2 - отдельная программа, которая рисует уже построенный граф.

## Почему DFS именно рекурсивный

В build_graph определена функция visit. Она записывает текущую вершину
и вызывает себя для каждой зависимости. Это обход в глубину: сначала
полностью обрабатывается одна ветвь, затем следующая.

На ромбе A -> B, A -> C, B -> D, C -> D порядок первого посещения:
A, B, D, C. BFS дал бы A, B, C, D, поэтому тест отличает алгоритмы.

## Как предотвращается бесконечная рекурсия

Вершина помещается в graph перед обходом ее соседей. Если она уже есть
в graph, visit сразу завершается. При этом ребро хранится в списке
зависимостей, поэтому цикл не теряется на изображении.

## Откуда берется порядок загрузки

В load_order вершина добавляется в список после всех ее зависимостей.
На ромбе результат D, B, C, A. У B и C нет зависимости друг от друга,
поэтому D, C, B, A тоже допустим. Именно поэтому порядок может отличаться
от pip, хотя зависимости в обоих случаях установлены раньше потребителей.

Для обнаружения цикла используются active и path. Если visit встречает
вершину из active, она находится в текущем стеке рекурсии. Можно показать
путь цикла. Строгая топологическая сортировка такого графа невозможна.

## Что такое D2

D2 - текстовый язык диаграмм. Пример:

```d2
direction: right
n0: "A"
n1: "B"
n0 -> n1
```

to_d2 назначает вершинам безопасные ID n0, n1 и сохраняет имена в подписях.
render вызывает команду d2 и проверяет результат. PNG не используется
как источник зависимостей, это только визуальное представление.

## Почему pipdeptree не нарушает запрет

Он использован только как независимый эталон для обязательного сравнения.
Программа в src не запускает и не импортирует pip или pipdeptree.
В трех реальных примерах сравнивались множества вершин и ребер: они
совпали. Общая зависимость в нашем графе одна, в дереве может повторяться.

## Какие ограничения нужно честно назвать

Программа строит граф метаданных последних версий, не устанавливает
пакеты и не решает ограничения версий. Это не замена pip. Условия среды
обрабатываются компактным собственным парсером, не всей спецификацией
PEP 440/508. Подробности и проверенные примеры находятся в README.
Глубина рекурсии ограничена Python; ошибка превышения обрабатывается.

## Что показать преподавателю

1. README, структуру папок и `git log --oneline --reverse`.
2. Этап 1 и несколько неверных параметров из docs/errors.md.
3. Прямые зависимости requests на этапе 2.
4. Ромб и цикл на этапе 3; порядок ромба и ошибку цикла на этапе 4.
5. Запуск этапа 5, файл D2 и PNG; три реальных примера.
6. Сравнение с pip/pipdeptree и запуск unittest.

Все команды приведены в README. Перед защитой стоит самостоятельно
пройти их и убедиться, что понятны DFS, посещенные вершины и постпорядок.
