# Эмулятор оболочки: вариант 26

Итоговая реализация команд варианта 26 на Python 3.8 или новее.
Сторонние библиотеки и сборка не нужны. Основной код — `src/main.py`.

ZIP читается без распаковки. VFS — словарь: абсолютный путь →
пара (содержимое, права). У каталогов содержимое равно `None`,
у файлов — строка base64. Все изменения остаются в памяти.
После выхода они теряются; исходный ZIP не изменяется.

## Запуск

Команды выполняются из каталога проекта:

```sh
python3 examples/make_vfs.py
python3 src/main.py --vfs examples/nested.zip
```

Запуск со стартовым скриптом:

```sh
python3 src/main.py --vfs examples/nested.zip --script examples/all.txt
```

Альтернативный запуск: `sh run.sh --vfs examples/nested.zip`.
Без `--vfs` создается пустая VFS с корневым каталогом `/`.
Без `--script` сразу начинается интерактивный ввод.
Параметры выводятся при запуске и по команде `conf-dump`.
Пути параметров отсчитываются от текущего каталога реальной ОС.

## Команды

| Команда | Действие |
| --- | --- |
| `ls [-a] [-l] [путь]` | Список файлов; `-a` включает скрытые, `-l` показывает восьмеричные права |
| `cd [путь]` | Перейти в каталог; без аргумента — в `/` |
| `history` | Показать введенные команды, включая текущую и ошибочные |
| `cal` | Календарь текущего месяца |
| `cal год` | Календарь года |
| `cal месяц год` | Календарь указанного месяца |
| `chmod права путь` | Установить права: например, `600`, `755`, `1755` |
| `cp источник назначение` | Скопировать файл; существующий файл назначения перезаписывается |
| `cp -r источник назначение` | Скопировать каталог со всем содержимым |
| `conf-dump` | Вывести `vfs=...` и `script=...` |
| `exit` | Завершить работу |

Если назначение `cp` — существующий каталог, копия создается в нем.
Рекурсивное копирование объединяет каталоги и перезаписывает файлы.
Копирование в себя и конфликты файла с каталогом запрещены.
Корневой каталог копировать нельзя.

Это небольшой эмулятор с перечисленными режимами команд.
`chmod` сохраняет права и показывает их через `ls -l`; ограничения доступа
по пользователям и группам не моделируются. Символьные режимы вроде `+x`,
конвейеры, перенаправления и остальные флаги UNIX не реализованы.

Кавычки обрабатывает `shlex.split`. Комментарии начинаются с `#`
вне кавычек. Скрипт показывает и ввод, и вывод; после ошибки команды
выполнение продолжается. `exit` останавливает скрипт и эмулятор.
Отсутствующий или некорректный ZIP завершает запуск с сообщением ошибки.
Ошибка чтения стартового скрипта выводится перед интерактивным режимом.

## Пример

```text
ls -a -l
cd a/b/c
ls
cd /
cp "my file.txt" "my copy.txt"
chmod 600 "my copy.txt"
ls -l
cal 10 2026
history
exit
```

## Проверки

```sh
python3 -m unittest discover -s tests -v
sh examples/run-minimal.sh
sh examples/run-files.sh
sh examples/run-nested.sh
```

Три сценария создают ZIP и проверяют минимальную VFS, VFS с файлами
и VFS с тремя уровнями каталогов. `examples/all.txt` содержит все
поддерживаемые режимы команд и примеры ошибок. ZIP исключены `.gitignore`.

## Функции основного кода

| Функция | Назначение |
| --- | --- |
| `Shell.__init__` | Создать состояние эмулятора и загрузить архив |
| `full` | Привести путь к абсолютному пути внутри VFS |
| `load` | Прочитать ZIP и добавить родительские каталоги |
| `require` | Проверить существование и тип объекта |
| `prompt` | Сформировать приглашение с реальными именами ОС |
| `conf_dump` | Показать конфигурацию |
| `ls`, `cd`, `cal`, `chmod`, `cp` | Выполнить соответствующие команды |
| `execute` | Разобрать строку, выполнить команду, вывести ошибку |
| `run` | Выполнить скрипт и запустить цикл ввода |
| `main` | Прочитать аргументы командной строки и запустить приложение |

## Сдача по этапам

В папке находится итоговый код; отдельной истории разработки нет.
По заданию этапы нужно сохранять отдельными коммитами в публичном
репозитории и демонстрировать на занятии. Для первого этапа `ls` и `cd`
должны быть заглушками, выводящими имя и аргументы; рабочая реализация
появляется на четвертом этапе.

Примеры сообщений для соответствующих этапов разработки:

```text
feat(repl): add quoted arguments, command stubs and exit
feat(config): add startup script and conf-dump
feat(vfs): load ZIP into memory and report errors
feat(commands): implement ls, cd, history and cal
feat(commands): implement chmod and cp
```
